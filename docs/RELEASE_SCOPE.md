# Release scope

This repository releases:

- the PACT operator, comparators, and typed-admission implementation;
- project-generated controlled source records with evaluation labels stored separately;
- deterministic tests and scene-grouped reproduction scripts;
- frozen topology-multiplicity, equal-cardinality topology, operator-characterization, random-order-reference, score-transport, exhaustive six-view coarsening, provenance-corruption, and joint-holdout outputs;
- no-media foundation-model logits and derived analyses, including the native-view provenance-transfer snapshot;
- aggregate H2O, public multi-view, and HABIT fixed-image/sequential and checkpoint-robust admission snapshots where redistribution permits;
- a claim-to-artifact map binding principal numerical claims to result files, analysis scripts, denominators, and hashes.

It does not release provider media, model weights, private infrastructure records, or physical-robot safety certification. Third-party materials remain subject to their original terms; public access to this repository does not grant rights to those materials.

No project-wide software or data license is asserted in the current artifact. A license should be added only after all authors and relevant institutions approve it.
